# X API 현황 노트 (2026-09-17 조사)

## 접근·가격
- 2026-02 무료 티어 폐지. 신규는 종량제(pay-per-use)만. Basic($200/월)은 2026-06-01 이후, Pro($5,000/월)는 2026-09-01 이후 종량제 강제 전환. Enterprise 별도
- 크레딧 선충전(최소 $5), 요청/리소스마다 차감. 동일 리소스 24h(UTC) 내 재조회는 1회만 과금
- 쓰기(요청당): 게시 $0.015 · 링크 포함 게시 $0.200 · 상호작용 삭제 $0.010 · 콘텐츠 관리 $0.005 · 북마크 $0.005
- 읽기(리소스당): 게시물 $0.005 · 사용자 $0.010 · 좋아요 $0.001 · **owned read**(내 게시물·멘션·북마크·팔로우 등 본인 소유) $0.001, 2026-04-20 시행
- 월 상한: 게시물 읽기 300만/청구 주기

## 속도 제한 (사용자 토큰 기준)
| 엔드포인트 | 한도 |
|---|---|
| `DELETE /2/tweets/:id` | 50 / 15min |
| `DELETE /2/users/:id/likes/:tweet_id` | 50 / 15min · 1,000 / 24h |
| `DELETE /2/users/:id/retweets/:source_tweet_id` | 50 / 15min |
| `POST /2/tweets` | 100 / 15min (앱 10,000 / 24h) |
| `GET /2/users/:id/tweets` | 900 / 15min (앱 10,000 / 15min) · 최근 3,200건까지 |
| `GET /2/users/me` | 75 / 15min |
- 응답 헤더 `x-rate-limit-limit` / `x-rate-limit-remaining` / `x-rate-limit-reset`(unix 초) → 클라이언트 스스로 페이싱 가능

## 인증
- OAuth 2.0 Authorization Code + PKCE(공개 클라이언트). 스코프 `tweet.read tweet.write users.read offline.access` (+`like.write`)
- access token 2h · refresh token 6개월·1회용(갱신마다 회전 → 저장은 직렬화 필수)
- 갱신 `POST https://api.x.com/2/oauth2/token` `grant_type=refresh_token`

## 데이터 아카이브
- 설정 → 계정 → 데이터 아카이브 다운로드. 생성 24h~수일
- `data/tweets.js`: `window.YTD.tweets.part0 = [ {tweet:{id_str, full_text, created_at, in_reply_to_status_id, entities, extended_entities, favorite_count, retweet_count, ...}} ]`. 대용량은 `tweets-part1.js` 등 분할
- 리포스트는 `full_text`가 `RT @`로 시작. 좋아요는 `like.js`

## 자동화 규칙 요지 (2차 출처)
- 공식 API 앱은 "인가된 애플리케이션". 비밀번호 로그인 스크립트·헤드리스 브라우저는 아님
- 가장 강하게 단속되는 행위는 대량 팔로우/언팔로우. 본인 게시물 삭제는 금지 항목 아님
- 계정 잠금 흔한 원인: 급격한 활동 스파이크, 새 기기/위치 로그인, 자동화 징후 → 삭제기도 "스파이크 없이 일정·저속"이 핵심
