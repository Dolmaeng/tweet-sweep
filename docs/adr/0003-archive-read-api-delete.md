# ADR-0003: 열람은 데이터 아카이브, 삭제는 API

- 상태: 확정 · 2026-09-17

## 맥락
- API 열람(`GET /2/users/:id/tweets`)은 최근 3,200건 한도 + 건당 $0.001(owned read)
- X 데이터 아카이브의 `tweets.js`는 전 기간·전 유형(원글·답글·리포스트) 포함, 무료. 생성 24h~수일

## 결정
- 열람·인벤토리는 아카이브 파싱. API 열람은 (a) 아카이브 이후 게시물 보충 (b) 삭제 검증 샘플링에만 선택 사용
- 삭제는 항상 API

## 이유
- 전체 이력은 아카이브만 제공. 비용 0. 오프라인 백업 겸용(헌장 P3)
- API 읽기 최소화 = 비용·호출 수 절감 = 이상 행동 신호 감소

## 대안과 기각 사유
| 대안 | 기각 사유 |
|---|---|
| API만으로 열람 | 3,200건 초과 불가, 유료 |
| UI 스크롤 수집 | ADR-0001 위반 |

## 결과·후속
- 아카이브 요청 즉시 시작. 파서는 `window.YTD.tweets.part0 = ` 접두 제거 후 JSON 파싱, 분할 파일 병합
- 아카이브 기준 시점 이후 게시물 처리 절차를 계획 문서에 명시
