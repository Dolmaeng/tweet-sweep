# ADR-0001: 삭제 경로는 공식 X API v2만 사용

- 상태: 확정 · 2026-09-17

## 맥락
- 목표 1순위 "계정 정지 건덕지 0". 자동 삭제 경로 3가지: ① 공식 API ② 브라우저 UI 자동화(Cyd 방식) ③ 비공식 내부 엔드포인트
- 2026-02 무료 티어 폐지로 ①은 유료(종량제). ②는 무료지만 X 약관은 "공개된 인터페이스 외 자동 접근"을 금지

## 결정
- ①만 사용. 등록한 개발자 앱 + OAuth 2.0 PKCE 사용자 토큰으로 `DELETE /2/tweets/:id`
- ②③은 실험 브랜치 포함 어떤 형태로도 코드베이스에 두지 않음

## 이유
- X 입장에서 ①은 "인가된 앱의 정상 사용". 한도(50/15min)가 문서화되어 예측·준수 가능. 본인 게시물 삭제는 금지 행위가 아님
- ②는 계정 세션으로 UI 조작 → 봇 탐지 대상, 약관 위반 소지, UI 변경 시 파손
- ③은 약관 위반 + 탐지 위험 최고
- 비용($0.005~0.010/건)은 계정 안전과 교환 가능한 수준

## 대안과 기각 사유
| 대안 | 기각 사유 |
|---|---|
| UI 자동화 도구(Cyd 등) | 약관 회색지대, 탐지 위험, 학습 목표(API·인증·백엔드)와 불일치 |
| 수동 삭제 | 수천 건 비현실적 |
| 제3자 삭제 서비스 | 토큰을 타인에게 위임 → 보안·안전 통제 상실 |
